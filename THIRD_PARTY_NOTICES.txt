sc3kre -- SimCity 3000 Unlimited reverse-engineering reference
https://github.com/nanofives/sc3kre
Reviewed revision: 0d1594ffad7f4bc2410e5ccb990fd0bf8deefaf4

Used as an attributed source of address, class and interface leads.
City-save format and optional-field grammar in src/city_map.c and its
reference check also adapt the upstream MIT Python parsing tools.
TKB1 primary-appearance extraction in src/city_sprite_definition.c adapts
sprite_patch.py format parsing, with installed SIMGEOM/SIMSPR checks.
Selected occupant attribute parsing in src/city_occupant_attributes.c also
uses sprite_patch.py/netmod/netpack.py TKB1 grammar leads, with the installed
SIMGEOM attribute loader, layer-mask getter and purpose selector checked. Local
NET_ART.md and netmod/exemplars.py/sprites.py also supplied network-art
resource and placement leads, checked against installed SIMNTWRK/SIMSPR.
The upstream functions.csv also supplies low-zoom display-list and dirty-
rectangle/spatial-grid interface leads, verified against installed SIMSPR before porting.
Local binary checks remain the authority for this reconstruction. No upstream game
binaries, extracted assets or decompiled game implementation are incorporated.
